# Aegis brand assets

The Aegis mark combines a shield and an A monogram. Its colors follow the app: terracotta `#B44A34`, charcoal `#262522` and ivory `#F6F3ED`.

| File | Use |
| --- | --- |
| `aegis-logo.png` | Transparent emblem and wordmark, for light backgrounds |
| `aegis-icon-transparent.png` | Transparent emblem, used in app navigation and the browser icon |
| `aegis-competition-logo.png` | Square emblem on ivory, suitable for a project listing |

`src/components/BrandMark.tsx` shares the emblem across the app. Vite generates a content-hashed asset URL during builds.

The raster assets were created with OpenAI image generation. See [attribution](../ATTRIBUTION.md).
