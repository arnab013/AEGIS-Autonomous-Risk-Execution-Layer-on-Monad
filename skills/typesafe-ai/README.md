# TypeSafe skill

Copied from the installed official TypeSafe plugin, version 0.5.7. Upstream: https://github.com/typesafe-ai/skills. The skill is MIT licensed; its live documentation remains the source of truth.

Skills contain instructions, not credentials. The project API reads `TYPESAFE_API_KEY` from its ignored `.env`; the hosted Worker uses a server secret with the same name. Run `node scripts/setup-typesafe.mjs` to configure the local key from `F:/Projects/jev_key.txt`.
